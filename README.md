# Login Form

Login Form Built Using HTML, CSS and JavaScript.

![Login Form Screenshot](./Screenshot%202024-08-03%20173338.png)

## Overview

A clean, responsive login form built with pure HTML, CSS and a small amount of JavaScript. This project demonstrates a simple and attractive UI for user authentication screens — perfect for learning, prototyping, or embedding into larger front-end projects.

Languages: CSS (54.3%), HTML (45.7%)

## Features

- Modern, minimal design
- Responsive layout that works on desktop and mobile
- Simple client-side validation (HTML5 and JavaScript)
- Easy to customize styles and branding

## Demo

Open the `index.html` file in your browser to see the login form in action:

1. Clone the repo or download the ZIP
2. Double-click `index.html` or open it with your browser

## File Structure

- `index.html` — main HTML file with the login form
- `style.css` — styling for the form and page
- `Screenshot 2024-08-03 173338.png` — screenshot used in this README
- `japan-background-digital-art (2).jpg` — background image used by the project

## Customization

- Change colors, spacing, and fonts in `style.css` to match your branding.
- Replace the background image file (`japan-background-digital-art (2).jpg`) with your own image.
- Extend the JavaScript to integrate with real authentication endpoints.
